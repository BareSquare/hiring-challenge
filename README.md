# Baresquare Hiring Challenge

## AI Analyst — SEO & Web Operations (Entry Level)

[Baresquare](https://baresquare.com) builds and deploys AI agents for enterprise clients like Sony, Adidas, and Vogue — automating real business workflows across analytics, SEO, and web operations.

Your job: make sure a global electronics brand's website ranks well on Google across **130+ locales**. You'll create SEO metadata, support SEO services, dig into analytics tools when errors spike, manage redirects, and talk to client teams across multiple countries. A lot of this work is manual and repetitive today. We want someone who'll learn it, then figure out how to automate it with AI.

**6-month paid internship** · Thessaloniki · Hybrid (3 days/week in office). SEO or analytics experience is a plus, not a requirement. Curiosity and comfort with AI tools are. People who enjoy figuring out how systems work and then automating them tend to thrive here.

**Indicative tools:** Adobe Analytics, Google Sheets / Excel, Jira, Claude Code, our AI-powered SEO platform

### What You'll Do

- **SEO metadata and keyword research**: Research keywords and create metadata (titles, descriptions, URLs) for the client's web pages using our AI-powered application
- **SEO services**: Provide SEO recommendations, best practices, and analysis to the client
- **Localization**: Adapt English metadata for local markets, coordinating with regional contacts
- **Error analysis**: The client's websites across 130+ locales are monitored automatically. When error rates spike, you'll dig into web analytics tools (Adobe Analytics) to figure out what happened — a broken deploy, a page restructure, a content removal — and decide what action to take
- **Redirects and broken links**: When pages move or disappear, ensure visitors and search engines reach the right destination. Manage redirect rules and coordinate fixes with the client's technical teams
- **Client communication**: Track issues in Jira, follow up with the client stakeholders, and send status updates
- **Workflow automation**: Identify repetitive work and build AI-powered solutions to replace it

### Requirements

- Strong written English
- Interest in SEO and how the web works in the AI era
- Advanced spreadsheet skills (Google Sheets / Excel)
- Analytical — can look at error reports and web analytics data, spot what's off, and decide what to do
- Regularly use AI tools (ChatGPT, Claude, etc.) to solve problems, learn new things, and get work done faster
- Bonus: knowledge of SQL, JSON, or basic Python

### Who You Are

- Self-directed and organized — you don't need someone checking on you daily
- Comfortable with repetitive, detail-oriented work
- Curious — you look things up, try things out, ask questions when stuck
- Communicative — you follow up without being asked

### What You Get

- You'll work directly with one of the world's biggest electronics brands — not on simulated projects
- You'll use and help build AI-powered tools that automate real operations
- Small team where your work is visible and has immediate impact
- A path into SEO strategy, automation, or client management

## The Challenge

> [!IMPORTANT]
> **You are not expected to know how to do any of this.** Most of the steps below will be new to you — GitHub, terminals, SEO, HTML. That's intentional. We want to see how you use AI tools (ChatGPT, Claude, etc.) to figure out problems you haven't seen before. The ability to learn with AI is the skill we're hiring for.

### Rules

- Use any tools you want: Google, ChatGPT, Claude, YouTube, whatever helps
- There's no single "right answer" — we're evaluating your process, reasoning, and communication
- You must share your AI conversations — share links for web-based tools (ChatGPT, Claude), or screenshots/logs for terminal-based tools (Gemini CLI, Claude Code). **This is not optional.**

---

### Part 1: Get Your Challenge File

1. **[Register here](https://bit.ly/4uJpqVn)** to receive your personalised `index.html` file by email. This also starts your **7-day submission window**.
2. Clone this repository to your computer — it contains the template files for your submission
3. Place the `index.html` file you received by email into the `site/` folder
4. Create a **private** repository on your own GitHub account and push the code there
5. Add `baresquare-hiring` as a collaborator on your private repo (Settings → Collaborators)

*Hint: If you've never used git or GitHub before, ask your AI assistant how to get started.*

### Part 2: The Work

The product page (`site/index.html`) has several problems that hurt its visibility on search engines (Google, Bing, etc.).

We recommend using a free AI coding assistant like [Gemini CLI](https://github.com/google-gemini/gemini-cli), GitHub Copilot, or Cursor to analyze the page and apply fixes — this is how we work day-to-day.

1. Find and fix at least 5 SEO issues on the page
2. For each fix, write a short comment in `FIXES.md` explaining: what was wrong, why it matters, and what you changed
3. Write a short brief to the client in `BRIEF.md` (max 1 page). See the file for what to cover

### Bonus (optional — do before submitting)

Done with the main work? Want to go further? These are optional but we notice when candidates go the extra mile.

- Publish your fixed page to a live URL (GitHub Pages, Netlify, Vercel — whatever works). Add the URL to `BONUS.md`.
- Write a short process doc in `BONUS.md`: "If a new colleague had to repeat this challenge, here's the step-by-step guide I'd give them."

### Part 3: Submit

1. Fill in `SUBMISSION.md` — AI conversation links and questions
2. Push all your changes to your private repo
3. Email your private repo link and your CV to hiring-challenge@baresquare.com
